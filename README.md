# Le Profil

Petit jeu de trail, en français. On choisit OCC, CCC ou UTMB, on crée un coureur, puis on enregistre des sorties (distance et dénivelé positif). L'avatar n'avance sur le profil que lorsque le tronçon en cours a ses kilomètres et son D+ couverts.

Les totaux reprennent des ordres de grandeur publics (édition 2025). Le dessin du profil est schématique : ce n'est pas un tracé officiel.

L'état reste dans le navigateur (`localStorage`).

## Lancer

```bash
npm install
npm run dev
```

Ouvrir http://127.0.0.1:5173

```bash
npm test
npm run build
```
